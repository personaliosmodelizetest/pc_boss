# 装机大亨 · PC Parts Tycoon

一款纯前端（HTML/CSS/JS，零依赖、零构建）的电脑配件**低买高卖模拟经营**网页游戏。打开 `index.html` 即可在浏览器中游玩。

## 玩法

- 回合制，每回合代表 **1 周**，共 **52 周（1 年）**。
- 每周开始会触发一个**市场事件**（如挖矿热潮、新品发布、内存减产、电商大促等），影响相关配件的价格。
- 8 种配件：CPU、显卡、内存、主板、固态硬盘、电源、机箱、散热器，价格围绕基础价做**均值回归 + 随机波动 + 事件冲击**。
- 受**现金**与**仓库容量**限制买入 / 卖出，可花钱扩建仓库。
- **目标**：一年内最大化净资产（现金 + 存款 + 库存市值），结束后给出评级（S/A/B/C/D/E/F）。
- 现金为负、存款为零且无库存可卖 → **破产出局**。

## 进阶机制

- **大宗商品（原油 / 铜）**：两个指数每周随机波动，并通过传导系数影响 **电源 / 机箱 / 散热器 / 主板** 的成本与价格；还有「地缘冲突推升油价」「铜矿罢工」等具名事件冲击指数。
- **存储链事件**：「存储颗粒厂大火」（减产→内存/SSD 涨）、「域外新厂投产 / 海外产能爬坡」（增产→内存/SSD 跌）。
- **银行存款**：闲钱可存入银行，年化 5.2%、每周复利、无风险；抄底时再取出。
- **装机档口月度订单**：每 4 周（每月）会有顾客上门装机，按「市场价 + 随机装机溢价(约 +3%~+10%)」收购你的部分库存。可**接单**（卖出平仓、收入有多有少）或**拒单**（留货等行情）。

## 价格模型

每周对每个配件：

```
成本系数 = 1 + Σ 传导权重 ×(大宗商品指数 - 1)        // 原油/铜传导
target = 基础价 × 季节系数 × 成本系数
price = price + (target - price) * 0.14            // 均值回归
price *= 1 + 正态噪声 * 波动率                       // 日常波动
price *= 事件倍率(若该配件受当周事件影响)             // 事件冲击
price = clamp(price, 基础价*floor, 基础价*ceil)      // 限幅
```

进度通过 `localStorage` 自动存档，刷新可继续；点「重新开始」清档重来。

## 运行

直接用浏览器打开 `index.html`，或起一个静态服务器：

```bash
python3 -m http.server 8000
# 浏览器访问 http://localhost:8000
```

## 文件

- `index.html` — 页面结构
- `styles.css` — 样式（深色主题）
- `game.js` — 全部游戏逻辑（配件、事件、价格模型、交易、结算、存档）
