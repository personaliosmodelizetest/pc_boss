# 装机大亨 · PC Parts Tycoon

一款纯前端（HTML/CSS/JS，零依赖、零构建）的电脑配件**低买高卖模拟经营**网页游戏。打开 `index.html` 即可在浏览器中游玩。

## 玩法

- 回合制，每回合代表 **1 周**，共 **52 周（1 年）**。
- 每周开始会触发一个**市场事件**（如挖矿热潮、新品发布、内存减产、电商大促等），影响相关配件的价格。
- 8 种配件：CPU、显卡、内存、主板、固态硬盘、电源、机箱、散热器，价格围绕基础价做**均值回归 + 随机波动 + 事件冲击**。
- 受**现金**与**仓库容量**限制买入 / 卖出，可花钱扩建仓库。
- **目标**：一年内最大化净资产（现金 + 库存市值），结束后给出评级（S/A/B/C/D/E/F）。
- 现金为负且无库存可卖 → **破产出局**。

## 价格模型

每周对每个配件：

```
price = price + (季节基础价 - price) * 0.12      // 均值回归
price *= 1 + 正态噪声 * 波动率                     // 日常波动
price *= 事件倍率(若该配件受当周事件影响)           // 事件冲击
price = clamp(price, 基础价*floor, 基础价*ceil)    // 限幅
```

进度通过 `localStorage` 自动存档，刷新可继续；点「重新开始」清档重来。

## 运行

直接用浏览器打开 `index.html`，或起一个静态服务器：

```bash
python3 -m http.server 8000
# 浏览器访问 http://localhost:8000
```

## 文件

- `index.html` — 页面结构
- `styles.css` — 样式（深色主题）
- `game.js` — 全部游戏逻辑（配件、事件、价格模型、交易、结算、存档）
